### Task 5: Listen to a man talking about data processing and fill in the gaps with NO MORE THAN TWO WORDS from the recording

> Data processing involves several key steps to transform raw data into useful information. It starts with data collection, where data is gathered from different **(1)** `sources`. Then, data sorting organizes the data into categories or specific orders for **(2)** `easier` access and analysis. Data coding converts qualitative information into **(3)** `numerical codes` *(hoặc `numbers`)*, followed by data entry, where the data is input into systems. **(4)** `Data validation` ensures accuracy and consistency, detecting any errors that could affect the analysis. Finally, data tabulation presents the data in tables or charts, making it easier to **(5)** `identify` *(hoặc `spot`)* patterns, trends or relationships.
